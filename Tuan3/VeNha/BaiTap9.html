Sử dụng Font Awesome

Các biểu tượng Font Awesome Free được liên kết bằng CSS. Tệp CSS và phông biểu tượng được lưu kèm bài làm nên có thể xem khi không có mạng.

  • Lập trình

    Biểu tượng mã nguồn.

    <i class="fa-solid fa-code" aria-hidden="true"></i>

  • Thiết kế

    Biểu tượng thiết kế giao diện.

    <i class="fa-solid fa-paintbrush" aria-hidden="true"></i>

  • Phát triển Web

    Biểu tượng máy tính và mã nguồn.

    <i class="fa-solid fa-laptop-code" aria-hidden="true"></i>

  • Học tập

    Biểu tượng sách đang mở.

    <i class="fa-solid fa-book-open" aria-hidden="true"></i>

  • Liên hệ

    Biểu tượng thư điện tử.

    <i class="fa-solid fa-envelope" aria-hidden="true"></i>

  • GitHub

    Biểu tượng nền tảng lưu trữ mã nguồn.

    <i class="fa-brands fa-github" aria-hidden="true"></i>

Cách liên kết

<link rel="stylesheet" href="vendor/fontawesome/css/all.min.css">

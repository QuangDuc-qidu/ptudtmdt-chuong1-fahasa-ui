# CSS nâng cao · Lab 07

Nguyễn Quang Đức · MSSV 31241026319 · Lớp 26C1INF50902702 (ST5)

## Mục tiêu

Thực hành document flow, định vị, float, bố cục nhiều cột, giao diện responsive, hiệu ứng CSS và hệ thống lưới Bootstrap.
